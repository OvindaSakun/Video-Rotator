# Video Rotator

Batch scripts and Python utility to rotate vertical/horizontal video files by 90° clockwise or counter-clockwise using FFmpeg.

## Requirements
- [FFmpeg](https://ffmpeg.org/download.html) added to system `PATH`
- Python 3.x (optional, for Python script)

## Usage
- Drag and drop video files onto `rotate_cw.bat` (90° clockwise) or `rotate_ccw.bat` (90° counter-clockwise).
- Or run `python rotate_video.py` in any directory containing videos.
